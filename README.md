# HandScroll

웹캠으로 손 모양을 인식해 현재 문서를 스크롤하는 백그라운드 프로그램 (Windows).

| 손 모양 | 동작 |
|---|---|
| ☝ 검지만 펴서 위를 가리킴 (나머지 손가락 접음) | 아래로 스크롤 |
| 🖐 손바닥을 활짝 펼침 | 위로 스크롤 |
| 그 외 / 손 없음 | 정지 |

제스처를 유지하는 동안 계속 스크롤되며, 스크롤은 **마우스 커서 아래 창**에 적용됩니다.

## 빌드

1. Python 3.11 설치 (MediaPipe 0.10.14는 3.9~3.12 지원)
2. 이 폴더에서 `build.bat` 실행
3. `dist\HandScroll.exe` 생성 → 이 파일 하나만 있으면 실행됩니다

## 사용

- `HandScroll.exe`를 더블클릭하면 콘솔 창 없이 작업 표시줄 트레이에 아이콘이 생깁니다.
  - 파란색: 대기 / 초록색: 스크롤 중 / 회색: 일시정지
- 트레이 아이콘 우클릭 메뉴
  - **일시정지**: 인식 중지 + 웹캠 해제
  - **카메라 미리보기**: 인식 상태 확인용 창 (ESC로 닫기)
  - **종료**
- 중복 실행은 막혀 있습니다.
- 윈도우 시작 시 자동 실행: `Win+R` → `shell:startup` → 열린 폴더에 exe 바로가기를 넣기

## 조정 (hand_scroll.py 상단)

| 변수 | 설명 |
|---|---|
| `CAMERA_INDEX` | 웹캠 번호 |
| `SCROLL_AMOUNT` | 1회 스크롤 양 (120 = 휠 한 칸) |
| `SCROLL_INTERVAL` | 반복 간격(초) — 작을수록 빠름 |
| `STABLE_FRAMES` | 제스처 확정까지 필요한 연속 프레임 수 (오작동이 많으면 올리기) |
| `STRICT_THUMB` | True면 검지 제스처에서 엄지도 꼭 접어야 함 |

## 참고

- 로그: `%LOCALAPPDATA%\HandScroll\handscroll.log`
- 일부 앱(관리자 권한으로 실행된 창)에는 스크롤 입력이 전달되지 않을 수 있습니다.
- 백신이 PyInstaller 단일 exe를 오탐하는 경우가 있습니다.
